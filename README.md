# PocketView
# Personal Finance Dashboard

PocketView is a personal finance dashboard designed to provide a clear and intuitive overview of an individual's financial activity. It allows users to monitor expenses, review financial summaries, manage budgets and track savings goals through a clean and responsive interface.

PocketView aims to simplify personal financial management by bringing essential financial information together in one place.

The application provides a dashboard where users can review their financial activity, register expenses and monitor spending across different categories.

## Features
- Financial overview: Displays key financial indicators, including balance, income, expenses and savings.
- Expense management: Allows users to register expenses through an interactive form.
- Transaction history: Displays recent transactions, including descriptions, dates, categories and amounts.
- Expense categorization: Organizes transactions into categories such as food, transport, entertainment, shopping, health and housing.
- Budget overview: Provides a visual representation of spending limits and budget distribution.
- Savings tracking: Includes a dedicated section for monitoring savings goals.
- Local data persistence: Stores transaction data using the browser's LocalStorage API.
- Responsive interface: Adapts to different screen sizes, including desktop, tablet and mobile devices.

## Technologies
| HTML5 | Application structure and content |
| CSS3 | Layout, styling and responsive design |
| JavaScript | Application logic and interactivity |
| LocalStorage API | Client-side data persistence |
| SVG | Vector graphics and dashboard visualizations |
| Google Fonts | Typography (DM Sans and Manrope) |


PocketView is an evolving project. Features and functionality may change as development progresses.
